# DSCI 552 Homework 3

Homework 3 for DSCI 552 - Machine Learning for DS.

## Structure

- `notebook/Satish_Manvika_HW3.ipynb`: completed Jupyter Notebook
- `data/AReM.zip`: AReM activity recognition dataset
- `requirements.txt`: required python packages

## Running the notebook

install the required packages:

```bash
pip install -r requirements.txt
```

Start Jupyter Notebook from the repository root:

```bash
jupyter notebook
```

Open `notebook/Satish_Manvika_HW3.ipynb` and run all cells in order.
